# Design New Skill from Tool Inventory

Execute **Phase 2** from @.claude/skills/skill-scaffold/SKILL.md.

## Prerequisites

- @temp/tool-inventory.yaml must exist (run `/extract-tools` first, or copy `tool-export.yaml` from your app repo)

## Steps

1. Read @.claude/skills/skill-scaffold/prompts/design_skill_prompt.md
2. Read @temp/tool-inventory.yaml
3. Read @.claude/skills/dev-automation/SKILL.md as reference
4. Write @temp/skill-design.md
5. Ask user to approve design before running `/scaffold-skill`
